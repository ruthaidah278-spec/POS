# POS Retail Pro (Flutter)

## Run it
1. Install Flutter (https://docs.flutter.dev/get-started/install) and run `flutter doctor`.
2. In a terminal: `flutter create pos_retail_pro`
3. Replace `pos_retail_pro/lib/main.dart` with the `lib/main.dart` from this folder.
   (Replace `pubspec.yaml` too, or just keep the generated one - no extra packages are needed.)
4. `cd pos_retail_pro` then `flutter run` (Chrome: `flutter run -d chrome`).

## Flow
Splash (Get Started) -> Login -> Home -> New Sale / Products -> Cart (New Sale) -> Payment -> back Home.
Bottom tabs: Home, Sales, Inventory, Customers, More (Settings -> Business Profile / Offline).
